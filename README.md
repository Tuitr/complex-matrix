# Калькулятор матриц с комплексными числами

Консольное приложение на Java для выполнения операций над матрицами, элементы которых — комплексные числа.

**Автор:** Майоров Никита Андреевич, НИУ ВШЭ (Нижний Новгород), ИМИКН, «Компьютерные науки и технологии»

## Возможности

- сложение и вычитание матриц;
- умножение матриц;
- деление матриц (`A / B = A · B⁻¹`);
- транспонирование;
- вычисление определителя (разложение по первой строке);
- вычисление обратной матрицы (через алгебраические дополнения: `adj(A) / det(A)`);
- проверка размерностей с понятными сообщениями об ошибках.

## Структура проекта

| Файл | Описание |
|------|----------|
| `ComplexNumber.java` | Класс комплексного числа: сложение, вычитание, умножение, деление, форматированный вывод |
| `ComplexMatrix.java` | Класс матрицы комплексных чисел и все операции над ней |
| `Main.java` | Точка входа: ввод матриц с консоли и текстовое меню |

## Требования

- JDK 14 или новее (в `Main.java` используется синтаксис `switch` со стрелками `->`).

Проверить версию: `java -version`

## Сборка и запуск

Из папки с исходниками:

```bash
javac *.java
java Main
```

Либо откройте проект в IntelliJ IDEA и запустите `Main`.

## Использование

1. Введите размеры матрицы `A` (число строк и столбцов), затем её элементы построчно.
   Каждый элемент — два числа через пробел: **действительная** и **мнимая** части.
2. Аналогично введите матрицу `B`.
3. Выбирайте команды из меню:

| Команда | Действие |
|---------|----------|
| `1` | A + B |
| `2` | A − B |
| `3` | A · B |
| `4` | A / B |
| `5` | транспонировать A |
| `6` | определитель A |
| `7` | ввести матрицы заново |
| `0` | выход |

Дробные числа вводятся через точку (`2.5`).

### Пример

Ввод (матрицы 2×2, затем команда `1` — сложение, `0` — выход):

```
2 2
1 2   3 0
0 1   4 0
2 2
2 -1  0 0
1 0   1 1
1
0
```

Здесь `A = [[1+2i, 3], [i, 4]]`, `B = [[2−i, 0], [1, 1+i]]`.

Результат A + B:

```
3.0+1.0i    3.0
1.0+1.0i    5.0+1.0i
```

## Обработка ошибок

Программа не завершается аварийно, а выводит сообщение `Ошибка: ...`, если:

- размерности матриц не подходят для операции (сложение, вычитание, умножение);
- матрица не квадратная при вычислении определителя;
- матрица вырождена (определитель равен нулю), поэтому обратной не существует;
- происходит деление на нулевое комплексное число.

## Ограничения

- Определитель считается разложением по строке, сложность O(n!), поэтому для больших матриц (n > 9–10) вычисления будут медленными.
- Вещественные числа хранятся в `double`, поэтому результаты могут содержать небольшие погрешности округления.
